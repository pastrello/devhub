# Homologação LXC Rocky Linux 9.9 — primeira inferência GPU

Data: 2026-11-22 (logs locais enviados pelo operador). Teste executado pelo operador, não por CI.

## Ambiente observado
- Proxmox VE 9, LXC Rocky Linux 9.9, contêiner IA-01.
- GPU NVIDIA GeForce RTX 3060 Ti 8192 MiB, driver 620.73.04, CUDA UMD reportada 13.5.
- Ollama 0.40.17, qwen3:4b.

## Evidência de sucesso
Comando: `ollama run qwen3:4b "Responda apenas OK."` devolveu texto de pensamento do modelo e finalmente `OK`; não devolveu HTTP 500.

```text
ollama ps
NAME        ID              SIZE      PROCESSOR    CONTEXT    RUNNER      UNTIL
qwen3:4b    359d7dd4bcda    3.2 GB    100% GPU     4096       llamacpp    4 minutes from now

nvidia-smi
GPU: NVIDIA GeForce RTX 3060 Ti
Memory-Usage: 3207 MiB / 8192 MiB
Temp: 49C; Pwr: 48W / 200W; GPU-Util: 0% at sampling (after inference)
```

`nvidia-smi` informou processos não identificados, comportamento possível por visibilidade PID em LXC; como `ollama ps` reportou 100% GPU e VRAM ocupada, o modelo estava na GPU. A ocupação aproximada observada era 39,1% da VRAM. Temperatura e potência são apenas uma medição pontual, não benchmark sustentado.

## Incidente anterior
Antes da execução bem-sucedida, Ollama retornava `llama-server binary not found`. Um diagnóstico posterior verificou que `/usr/lib/ollama/llama-server` era executável ELF, legível pelo usuário ollama e visível no namespace do serviço. O reparador recusou sobrescrita por encontrar o arquivo; **não há evidência suficiente para atribuir a resolução a uma alteração específica**, e não se deve afirmar que uma mudança de permissão resolveu o problema.
